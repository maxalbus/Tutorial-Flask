GERENCIADOR DE TAREFAS - FRONT-END

1. Instale Python no computador.
2. Abra o terminal dentro desta pasta.
3. Execute:
   pip install -r requirements.txt
4. Execute:
   python app.py
5. Abra no navegador:
   http://127.0.0.1:5000

TELAS:
- /       = tela inicial
- /login  = tela de login
- /tarefas = tela principal de tarefas

Observação:
Este projeto é uma demonstração de front-end. O login e as tarefas ainda não usam banco de dados.
